# Shootout 0.4.3, fertig zum Spielen

1. Shootout_Windows.zip anklicken, dann rechts "Download raw file".
   Oder unter Releases: https://github.com/real-rusher/Shootout/releases/tag/spiel-0.4.3
2. Entpacken, Shootout.exe starten.
3. Beim ersten Start fragt Windows nach der Firewall: Zulassen, sonst geht LAN nicht.

Alle Mitspieler brauchen dieselbe Version (0.4.3), sonst lehnt der Host ab.
